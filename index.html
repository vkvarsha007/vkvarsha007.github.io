About

From the stored procedure to the screen.

I'm a .NET Full Stack Developer with 1.6 years of professional experience. At Realiser Labs Pvt Ltd I work on projects for the US client BOLD Precious Metals: the customer-facing eCommerce platform that sells gold, silver and platinum bullion, and Cerebro, the internal application the team uses to manage and run the website.

I own features end to end. I write the SQL Server queries and stored procedures, build the APIs in .NET Core and ASP.NET MVC, create the Angular screens, then unit test, fix bugs and deploy to the testing servers.

Along the way I have added AI features with Claude and Gemini and automated a daily report that posts itself to Microsoft Teams. I care about clean, maintainable code and applications that stay fast.
